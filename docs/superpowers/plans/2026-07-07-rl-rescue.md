# RL Rescue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a minimal, backward-compatible rescue path for CKG-RL so a single-seed smoke run can test whether RL improves a strong `content_masked_sup` checkpoint instead of overwriting it.

**Architecture:** Keep old behavior as the default. Add an optional init checkpoint loader that copies only `model_state` before static training, and add a residual scale that blends simulator output with the supervised item vector.

**Tech Stack:** Python, PyTorch, PowerShell runner, existing FAST3 static protocol tests.
