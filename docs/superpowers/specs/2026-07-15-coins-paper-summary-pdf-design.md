# COINS 论文精读摘要 PDF 设计

## 目标

将《COINS: Semantic Ids Enhanced Cold Item Representation for Click-through Rate Prediction in E-commerce Search》的中文精读内容整理为一份 A4 学术摘要 PDF，方便研一阶段快速复习和后续复现。

## 内容范围

- 论文信息与作者署名信息；
- 一段式概括、研究背景与冷启动问题定义；
- RQ-OPQ Semantic ID、Adaptive Gate、KL 迁移和 OPQ 对比学习；
- 离线数据、基线、AUC/GAUC 结果、消融实验和线上 A/B 测试；
- 优势、局限、证据质量判断；
- 面向课程推荐冷启动的迁移思路与复现路线。

## 版式设计

- A4 纵向，中文字体使用系统可用 CJK 字体；
- 蓝灰色学术风格，标题层级清晰，页眉包含论文简称；
- 使用简化流程图表达“RQ 共性信息 + OPQ 个性信息 + 自适应门控”；
- 关键公式采用等宽或数学友好字体，并配中文解释；
- 表格保留主要离线指标和消融指标；
- 页脚包含页码、来源 DOI 和“基于论文正文整理”的说明。

## 验收标准

1. PDF 可正常打开，页数约 6–8 页；
2. 中文无乱码，公式、表格和流程图不发生裁切或重叠；
3. 关键数值与论文 Table 1–3 一致；
4. 输出文件位于 `output/pdf/`，文件名稳定且可直接下载；
5. 生成后渲染全部页面进行视觉检查，并用 PDF 文本抽取和页数检查验证内容。
