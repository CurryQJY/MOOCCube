# CKG-RL V3.5 Counterfactual Action Distillation Design

## Objective

V3.5 tests the remaining falsifiable USIM hypothesis after V3.3 and V3.4:
the legal target-free action space contains useful actions, but PPO does not
reliably identify them.  The route replaces PPO with offline counterfactual
action distillation while keeping the V3.2 teacher, vector generator, action
space, and deployment rollout unchanged.

This is a viability experiment, not a final main-table run.  Its only model
selection signal is pseudo-cold `P_val`; it does not load `static_test.pkl`.

## Fixed Protocol

The following stages must be bitwise-equivalent to V3.2/V3.4 for seed 2025:

- The strict-cold outer split and the deterministic `H_G`, `P_train`, and
  `P_val` item partition.
- `CleanTeacher` trained on `H_train` and selected on `H_val`.
- `ContentGenerator` trained only on `H_G` with the V3.2 vector objective and
  its internal `H_G` validation selection.
- Legal state-nearest top-20 user retrieval, the rollout state transition,
  `END` action, state projection, full-ranking evaluator, and target-free
  inference path.
- The optional catalog-only course signal as an inference-legal candidate-logit
  bias.  It is not a privileged action-label term.

The V3.5 manifest records the teacher and generator hashes, requires
`generator_rank_loss=false`, `policy_optimizer=action_distillation`, and
`test_loaded=false`.

## Training-Only Action Teacher

For an item `i` at state `h_t`, let `A_t(i)` be the exact legal retrieved user
candidates and append the legal `END` action.  The frozen teacher exposes an
item vector `e_i` and the train-only fixed user panel `U_i` for pseudo-warm
items only.  For every user action `a`:

```text
h_t(a) = h_t + step_size * u_a
g_t(a) = KL(q_T(e_i, U_i) || q(h_t, U_i))
       - KL(q_T(e_i, U_i) || q(h_t(a), U_i))
g_t(END) = 0
pi_T(a | h_t, i) = softmax(g_t(a) / action_temperature)
```

`q` is the existing rank-panel distribution with `rank_temperature=0.20`.
The fixed action temperature is `0.005`, chosen before implementation from a
read-only V3.4 action-space audit: it retains soft alternatives while giving a
mean top-label probability of about 0.35.  No `C_val`, `C_test`, target-cold
vector, or target-cold interaction enters this computation.

The actor is trained by cross entropy from `pi_T` to its own distribution,
including the `END` action.  Training states are generated by the actor's
current greedy target-free policy.  The action teacher labels those states
offline; gradients do not pass through the state transition.  This on-policy
state collection avoids a one-step teacher-forcing distribution mismatch while
remaining an ordinary supervised objective.

## Selection and Data Visibility

The script loads the train/validation split only, because `H_val` and `C_val`
reside in the same fixed validation file.  It immediately filters that file to
`H_val` before constructing its internal partition, so the V3.5 partition has
an empty `C_val` view.  It uses only `H_val` for teacher selection and does not
score or export `C_val` during training or checkpoint selection.
`static_test.pkl` is never opened.

For each epoch, the script measures the full target-free deployment rollout on
`P_val`, then uses the frozen teacher only to calculate its panel-KL gain.  The
eligible set is epoch 0 plus epochs with non-negative `P_val` gain.  The
selected checkpoint maximizes `P_val` gain, breaking ties toward lower epochs.
Epoch 0 is the unchanged vector-generator identity baseline.

The existing seed-2025 `C_val` and `C_test` metrics have been inspected in
earlier exploratory work.  Therefore neither may be presented as fresh
confirmatory evidence for V3.5.  If the P-only screen passes, a separately
predeclared fresh outer split/seed is required before any paper-level test
claim.

## Predeclared Falsification Gates

The first seed-2025 screen passes only when all of the following hold:

1. Teacher and generator hashes equal the V3.2/V3.4 vector-generator control.
2. At least one non-identity checkpoint has `P_val` rank gain strictly greater
   than zero and is selected.
3. The selected policy is target-free at inference and its only candidate set
   is legal state retrieval.
4. The recorded action label has shape `[batch, candidate_count + 1]`, includes
   `END`, and is a finite probability distribution.

Failure of any gate rejects the current USIM action-distillation formulation.
It must not be expanded into a multi-seed campaign or presented as a main
method result.
